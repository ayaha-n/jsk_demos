# Yomogi

`Yomogi-Regular.ttf` is the handwriting font of the picture book, from the
[Yomogi project](https://github.com/satsuyako/YomogiFont), under the SIL Open
Font License 1.1 (`OFL.txt`, kept with it).

It is the same file as plush_memory's `eink-viewer/fonts/Yomogi-Regular.ttf`,
which the tablet writes with. PDFs and the Web picture book use this copy, so
they lay lines out exactly as the tablet does, and work without plush_memory.
Update both copies together; `tests/test_storybook.py` checks they match.

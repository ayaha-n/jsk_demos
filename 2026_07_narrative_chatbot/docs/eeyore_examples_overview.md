# eeyore_birthday trainset 一覧

`pooh_eeyore_examples.py`の`EEYORE_BIRTHDAY_TRAINSET`に含まれるexampleの一覧。
`current_scene`は表示専用でDSPyの出力フィールド値であり、制御フローには使わない
(詳細は`scenarios.py`の`SceneDefinition`と`AGENTS.md`を参照)。
このファイル自体もリストの並び順(1a→1b→2→3→4a→5→6)に合わせている。

## 場面ID一覧(`scenarios.py`)

| 場面ID | 内容 |
|---|---|
| 1a | プーがハチミツを贈ると提案する |
| 1b | 参加者が別の贈り物を提案する |
| 1c | プーが自発的にハチミツを贈ると決める(無入力での自動発生) |
| 2 | 一口だけのつもりで持ち出す(伏線・自動発生)、および贈り物決定後〜実食までの準備待ち |
| 3 | プーが蜂蜜を食べてしまう(自動発生) |
| 4a | 空になった壺をそのまま贈ることにする |
| 4b | 蜂蜜以外の贈り物に切り替える |
| 5 | 決めた贈り物を振り返る |
| 6 | 贈り物の準備を詰める(色などの詳細を相談する) |

`1c`・`3`は`narrative_events.py`の必須auto-fireイベント
(`honey_gift_committed`→`pooh_tastes_honey`→`pooh_ate_honey`)がそのまま対応するため、
手書きexampleは存在しない(場面3の直後の会話exampleは残っている)。

合計23ブロック、dspy.Example換算で46件。

`pooh_preferences`(`GeneratePoohResponse`の入力)は`{unresolvedラベル: 好みの説明}`の辞書で、
現在の`unresolved`に実在する項目の好みだけが`narrative_state.relevant_preferences`で
フィルタされて毎ターン渡される。eeyore_birthdayは風船の色(青)とリボンの色(赤)の
2件を登録済み。

## RESPONSE_EXAMPLES への追加分(世界イベントの固定応答例)

trainsetとは別に、`fixed_response=True`のauto-fireイベント用に2件を追加している。
これらは`world_event`入力ありの固定応答パターンの教師例であり、`current_scene`は持たない。

| イベント | 内容 | bot_response |
|---|---|---|
| `pooh_ate_honey` | 蜂蜜を全部食べてしまった直後 | `HONEY_EATEN_RESPONSE`(いやんなっちゃう！味見してたら…) |
| `honey_gift_committed` | 無入力でハチミツの贈り物を自発的に決めた直後 | `HONEY_GIFT_COMMITTED_RESPONSE`(そうだ！ぼくは…) |
